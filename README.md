# Restaurant Menu Management

Digital menu system with menu creation, categorization and real-time updates.

- `index.html` – customer menu (category filter, veg/non-veg, sold-out tags)
- `admin.html` – add / edit / delete items and categories, toggle availability
- Real-time: changes in admin show instantly on the open customer page (same browser, via localStorage + BroadcastChannel)

## Run
Open `index.html` in a browser. Open `admin.html` in another tab and edit.

## Deploy (GitHub Pages)
Repo Settings → Pages → Branch `main` / root → Save.

## Tech
HTML, CSS, vanilla JavaScript.
